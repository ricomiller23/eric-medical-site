# ERIC Medical Site

A premium, interactive medical portal for tracking Multiple Myeloma treatment and education.

## Features

- 🧬 **Animated DNA Helix** - Real-time visualization of genetic profile with highlighted abnormalities
- 🔬 **3D Chromosome Display** - Interactive FISH probe results visualization
- ✨ **Particle Background** - Floating cell-like particles for immersive experience
- 🎨 **Glassmorphism UI** - Modern frosted glass card design
- 📊 **Interactive Charts** - Quality of life trajectory visualization
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile
- 🌙 **Dark/Light Mode** - Toggle between themes
- 🖨️ **Print-Ready** - Optimized for printing medical records

## Sections

1. **Dashboard** - Overview with quick stats and timeline
2. **Diagnostics** - Bone marrow, FISH panel, lab results
3. **Treatment** - D-RVd protocol with drug mechanisms
4. **Prognosis** - Survival scenarios and QoL projections
5. **Resources** - External links and appointment tools

## Tech Stack

- HTML5, CSS3, JavaScript (ES6+)
- Chart.js for data visualization
- Font Awesome icons
- Google Fonts (Inter)

## Local Development

Simply open `index.html` in a browser, or use a local server:

```bash
npx serve .
```
